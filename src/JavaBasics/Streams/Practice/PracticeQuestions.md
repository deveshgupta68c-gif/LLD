# Practice Questions on Lambdas and Streams

## Beginner
1. Print all even numbers from a list.
2. Count strings starting with "A".
3. Find the max element using `reduce()`.
4. Convert a list of words to uppercase.
5. Filter out null or empty strings.

## Intermediate
6. Group employees by department and count.
7. Find the second highest salary.
8. Join distinct city names alphabetically using `;`.
9. Get total transaction amount per customer.
10. Flatten a list of lists into one list.

## Advanced
11. Find the most expensive item per category.
12. Compute average salary per department.
13. Implement pagination using `skip()` and `limit()`.
14. Benchmark sum with parallel vs sequential streams.
15. Flatten `Map<String, List<Integer>>` to a single list.

## Bonus
16. Use `Optional` with `findFirst()` and `ifPresent()`.
17. Use `Collectors.partitioningBy()` to split even/odd numbers.
18. Find common elements between two lists using streams.
